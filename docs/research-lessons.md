# Lessons from executed research

These lessons change search order and test quality, not the frozen pursuit threshold.

- Start with a costly, owned workflow and a credible paid category. Find technical primitives that change it. A surprising list of repository names is not sufficient.
- Inspect simple alternatives before building. The microscopy candidate beat uncertainty ranking but lost to a threshold-margin rule; comparing only with the weaker baseline would have created a false success.
- Distinguish known methods from differentiated implementation. dblect already proposed temporal incremental-model testing; a working dbt bridge did not erase that prior art.
- Ask an independent reviewer for adversarial controls. A LiDAR tile's observations need not touch every nominal boundary. The initial synthetic test labeled valid geometry as erroneous and missed three cross-artifact contradictions.
- Use real data or an unchanged real engine where accessible. Declare exactly which claim a synthetic fixture proves. Cartonization witnesses show actual heuristic behavior on synthetic cuboids, not warehouse prevalence or invoice savings.
- Keep every relevant failed run, immutable preregistrations, exact versions and raw evidence. Packaging improvements must preserve the original evaluated source bytes.
- A bounded commercial experiment may investigate willingness to pay; it cannot claim that willingness has already been demonstrated. Prospective outreach is a plan, not permission to contact anyone.

The proposal/research prompts now emphasize buyer workflow, necessary cross-field components, strong simple baselines and honest execution claims. Existing v1 scoring and historical decisions remain unchanged. The separate v2 assessor requires reviewed executed evidence.
