# Rights and provenance for the font Stage0 screen

Source-only experiment; third-party font binaries, wheel binaries, full proof/source copies and README material are not included in the proposed publication packet. No fonts are modified or sold. Proposed future pricing concerns an engineering corpus-preparation service, not selling these font binaries separately.

- FiraCode5.2 and6.2 exact font bytes and release archive hashes are recorded in `font-input-inspection.json`. The LICENSE at each corresponding Git tag was downloaded and read; it identifies the Fira Code Project Authors and SIL Open Font License1.1. Minimal generated proof snippets are reported with source attribution. The raw working archives remain private.
- FontTools4.60.0 uses MIT. The exact installed wheel includes its MIT LICENSE plus LICENSE.external describing bundled test font/software notices; hashes are in `dependency-rights-inspection.json`. No third-party test font is used by our controls; controls build a synthetic font from original definitions.
- uharfbuzz0.53.2's Python wrapper uses Apache2.0, confirmed by the installed wheel's actual LICENSE. It embeds HarfBuzz12.3.0, which is separately licensed; it must not be described as all-Apache. The exact uharfbuzz tag points its HarfBuzz submodule to`b0af59229cc233a66106c696534ac39be56093d8`. [COPYING at that commit](https://github.com/harfbuzz/harfbuzz/blob/b0af59229cc233a66106c696534ac39be56093d8/COPYING) was read and specifies Old MIT, with subdirectory-specific notices where applicable. No wrapper/HarfBuzz binary is republished.
- Z3-solver4.15.3.0 is installed and hash-pinned for possible later work, but **unused in Stage0**. Installed metadata says MIT, but the wheel lacks a license file; a completed exact Z3 source/subcomponent audit is required before any later bridge-distribution claim. No claim of an executed Z3 integration is made here.
- The downloaded wheel bytes match the SHA256 published by PyPI for the exact platform filenames, as recorded in `dependency-pins.json`. No package import triggered font shaping; only version metadata was queried before preregistration.
- Diffenator2/3/fontFeatures source is privately inspected with exact commits and hashes in `source-inspection/manifest.json`. These tools are neither copied into our source nor claimed to have been run. Their existing features are discussed in the screening report. Their full distribution/dependency rights are not inferred from repository labels.

These checks support a local, source-only reproducible research screen. They do not assert exclusive rights, patent clearance or clearance for a closed-source future product. A future product's exact distribution would require its own dependency audit.
