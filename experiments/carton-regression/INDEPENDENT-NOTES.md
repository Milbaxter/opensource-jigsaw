# Parent research notes before benchmark completion

Observed 2026-09-18; hypotheses, not a pursuit judgment.

- [Kodaris release KOR-154](https://www.kodaris.com/content/releases/kor-154-release), issue KOD-29391, documents a UPS dimensional-weight/cartonization correction and a concrete regression scenario: 50 items should be grouped into approximately 5–7 cartons instead of 25. This is primary evidence of a real integration failure and an existing manual regression approach, not evidence the proposed generator would detect it.
- [Cycle Labs](https://cyclelabs.io/blog/off-the-shelf-testing-for-complex-wms-landscapes/) describes testing cartonization-rule changes in warehouse context. [Veridian](https://veridian.info/services/system-optimization/) sells warehouse optimization with automatic regression testing. These establish an adjacent paid workflow and incumbent competition, not demand for this particular audit.
- [Columbia's metamorphic runtime checking report](https://mice.cs.columbia.edu/getTechreport.php?format=pdf&techreportID=1550) already tests GAFFitter, a genetic bin-packing program. Applying metamorphic tests to packing is therefore not a new research concept. The candidate must stand on practical evidence for generating compact, independently valid, fee-consequential regression witnesses.
- [Paccurate's on-demand cartonization documentation](https://docs.paccurate.io/docs/on-demand-cartonization) already supports cost-aware generated boxes and price thresholds. A fee calculator alone is not a differentiated combination; Paccurate also supplies simulation and rule-management capabilities.

Technical findings cannot establish real shipping savings without operational constraints, actual contracted tariffs, and representative orders. A feasible smaller carton witness only proves the explicitly modeled geometric and tariff-component result.
