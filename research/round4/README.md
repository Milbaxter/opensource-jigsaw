3. **Ultrasonic reconstruction:** investigate an actual Fourier-method transfer on openly licensed measured signals, with established migration/TFM methods as comparators. [Commercial context](parent-sources/ultrasonic-commercial-evidence.md) documents existing fast postprocessing and input-access limitations.

None has an accepted performance result at this stage. No customer communication or purchases have occurred. Any prospective experiment must freeze its inputs, comparisons and failure rules before evaluation.
