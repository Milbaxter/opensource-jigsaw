# Ultrasonic reconstruction follow-up: workflow and baselines

Observed 2026-09-18. No experimental outcomes or new-product demand claimed.

- [Eddyfi on PWI/TFM postprocessing](https://blog.eddyfi.com/en/data-analysis-and-postprocessing-of-plane-wave-imaging-total-focusing-method-data): actual software already supports reprocessing region, pixel count, modes, geometry and velocity. Its example processes 300 scan positions at 316kpixels in about90seconds on an i7-8750H laptop. Customers can request a library for their own FMC processing; a Python example is linked. Raw elementary data often is not retained due size, so customer access cannot be assumed. CIVA/CIVA Analysis are named direct alternatives. These are supplier measurements, not independently rerun results. A faster prototype must identify a batch workload where its gain matters, rather than claim all industrial TFM remains slow or unavailable.
- [TWI FMC services](https://www.twi-global.com/what-we-do/services-and-support/asset-management/non-destructive-testing/ndt-techniques/full-matrix-capture) establish a current service category and optimized real-time TFM among existing methods. No fee was verified.
- [NASA 2023 CIVA maintenance procurement](https://sam.gov/workspace/contract/opp/b91ab24ed23d4ac59220f57d0949dc79/view), notice80NSSC23838088Q, explicitly seeks commercial CIVA maintenance from Extende for Langley. This is buyer-origin evidence of paid software upkeep, not an award amount, current2026pricing or a budget for this proposed narrow kernel.
- [Applus Canada supplier contract announcement](https://www.applus.com/ca/en/news/applus%2B-in-canada-secures-landmark-contract-for-canada%E2%80%99s-first-iwex-landline-initiative) describes a 2024 IWEX landline contract and real-time reconstruction. It also explicitly credits seismic and medical-imaging ideas, so cross-field reconstruction itself is known. No contract value or entrant advantage was established.

A secondary procurement aggregator mixed a$12,000 training award with$77,000 software prose and expanded CIVA incorrectly. Those amounts are excluded unless independently verified against the actual primary award. Hardware or full inspection budgets must not be presented as software-kernel value.

A plausible experiment is offline batch accuracy/runtime evaluation on licensed real signals, then a capped qualified-user integration study. It cannot establish code-compliant detection, flaw acceptance, structural integrity, or operational inspection approval from a single public lab specimen. Direct commercial software comparison and actual data availability remain material pilot questions.

Further baseline checks, before performance results:

- [EXTENDE's current CIVA UT Analysis description](https://www.extende.com/civa-ndt-simulation-software/modules-available-in-civa/ultrasonic-testing-analysis-with-civa/) includes postprocessing, configurable repeated actions, indication tables, reports and TFM reconstruction. A generic Python workflow/report layer cannot be assumed to introduce these capabilities. These supplier descriptions establish alternatives, not independently measured performance.
- [Zhuang et al., Sensors2020](https://doi.org/10.3390/s20174951), [author-institution copy](https://research-information.bris.ac.uk/files/258439357/sensors_20_04951_v2.pdf), compares time-domain and frequency-wavenumber imaging. Its reported400×300-pixel example lists minimum memory26MB for TFM versus1100MB for wavenumber reconstruction, with different PWI alternatives. These historical implementation numbers motivate measuring memory but cannot predict present streamed baselines, current commercial performance, or customer value. PWI changes acquisition information and is not a like-for-like reconstruction baseline for a saved FMC file.
