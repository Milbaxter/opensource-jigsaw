# Round five: measured machinery signals

No pursuit pass. This screen runs alongside the round-four ultrasonic prototype; it does not change its frozen protocol.

- **Tacholess speed recovery — HOLD.** [Feasibility review](tacholess/FEASIBILITY.md) and [primary download observation](tacholess/parent-browser-observation.json) establish usable licensed real vibration/encoder input. The proposed librosa/Astropy combination has no demonstrated advantage over existing multi-order tracking. Astropy noise-only false-alarm probability is not shaft-frequency correctness and its multiharmonic mode does not implement that statistic. No estimator or benchmark ran.
- **Independent-cart fault attribution — HOLD.** [Source review](moira/FEASIBILITY.md) found that every three-cart experiment assigns the fault to the middle cart. Predicting that position can exploit the setup instead of identifying a fault source. The dataset cannot validate the proposed fleet-attribution claim without new independently varied fault placement. No large archives or performance evaluations were attempted.

[Additional buyer and technical context](parent-sources.md) distinguishes existing monitoring contracts from evidence for the proposed cart-specific benefit.

[Three further reserve screens](reserve-screens/SCREEN.md) cover survey resurvey triage, mirror inspection planning and acoustic measurement selection. None has an executed comparative result. Andasol mirror measurements support a real recurring workflow but lack the dates needed for the proposed prospective split.
