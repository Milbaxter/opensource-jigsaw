# Parent reserve screen: scheduled wireless-audio coordination

18 September 2026. **HOLD before prototype.** Proposed combination: an open spectrum/file parser, NetworkX interval/conflict representation and an exact constraint solver, to coordinate mixed wireless microphones across event time slots. The putative transfer was scheduling with interference constraints, delivering a reviewed offline assignment with explanations. No software was installed, measurements downloaded, receiver contacted, or candidate evaluated.

The paid workflow exists: the [Society of Broadcast Engineers](https://sbe.org/resources/frequency-coordination/) lists event coordinators and explicitly distinguishes some fee-charging services from its volunteer network. Land-mobile/FCC application fee schedules are a different service and must not be used as microphone-planning prices.

The presumed timing gap does not survive primary product inspection. [SoundBase groups](https://docs.soundbase.app/guides/groups/) have time-of-use ranges, and its [time-of-use documentation](https://docs.soundbase.app/guides/groups/setting-time-of-use/) describes scheduling reuse. [Zones](https://docs.soundbase.app/guides/zones/) configure interactions between physical spaces. [Shure RF zones](https://content-files.shure.com/Pubs/WWB/en-US/en-US/rf-zones.html) likewise support reuse across suitably separated areas. These features were documented, not independently benchmarked.

An OSS comparator is also stronger than a plain frequency list: [RFutils](https://github.com/stoatworks-labs/RFutils) advertises mixed-equipment profiles, band and raster constraints, third/fifth-order intermodulation checks, locked assignments and WWB/WSM interchange. The README distinguishes sourced radio profiles from assumptions and warns that some hardware integrations remain untested. Those claims are not proof of algorithmic optimality, nor permission to weaken a baseline to generic graph coloring.

An exact solver could still find a better assignment or explain an infeasible plan. This screen found no rights-cleared difficult show instance on which competent SoundBase/WWB or an existing simple coordinator demonstrably failed, and no concrete buyer requirement for the proposed explanation output. A deliberately constructed graph-coloring win would not establish this missing workflow benefit. No final component/data license audit or pursuit score was attempted. Reopen only around a specific consented or lawfully public planning case with fixed physical assumptions, baseline settings and a prospective measurable advantage. Any operational radio decision would remain outside this research's authority.
