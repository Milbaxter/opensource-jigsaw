# Round three: integrations into paid work

The frozen v2 pursuit bar remains unchanged. Round two produced reproducible technical findings but no accepted commercial hypothesis. Current discovery begins with documented recurring work and asks whether an OSS integration can improve a defined part of that work.

- **BAS data onboarding:** historical public procurement documents price point mapping; a public labeled building dataset may enable a non-leaking comparison. Data/schema inspection is in progress. Anonymized identifiers cannot support claims about original-name mapping accuracy.
- **MEP equipment-access options:** [prospective protocol](../../experiments/mep-access/PREREGISTRATION.md) combines IFC geometry, robotics motion planning and joint intervention-set optimization. It measures a synthetic geometric/proxy advantage, leaving actual analyst-time savings to a later qualified study. Existing engineering services and planning literature are explicit comparators.

No v2 pass yet. No customer communication or purchases have occurred. A future pass would authorize a named bounded validation experiment, not establish profitability or operational safety.
