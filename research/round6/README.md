# Round six: data delivery and digital-production tests

No pursuit pass. Research is in progress, before candidate performance evaluation. The frozen v2 thresholds and evidence gates are unchanged.

- **Scientific-array partial replicas:** investigate whether optimization can choose useful partial copies under a storage budget, measured against good single/sharded layouts, query-specific materialization and greedy/LRU caches. Authentic public workflows and exact IO semantics are being checked; tutorials that eagerly load all data must not be relabeled as lazy queries.
- **Font-release behavioral witnesses:** investigate whether compiler-style constraint solving can synthesize executable strings for changed OpenType behavior beyond wordlists and simple context enumeration. [Primary commercial/workflow notes](font-commercial-evidence.md) show a concrete test-authoring task and paid QA category; no entrant demand or technical advantage is established yet. Existing font diffing, rule extraction and proof tools are required comparators.

The aim is a small decisive comparison before building a larger prototype. Known algorithms can qualify through useful measured integration; an unusual dependency list cannot.
