Manual Astra source inspection, not a generated pipeline result. Nine mechanisms were screened; none is ready for a performance protocol or a pursuit judgment. ## 1. CTDL condition-profile linking — HOLD

**Purchased deliverable hypothesis:** a maintained extraction-repair component for education catalog publishers, preserving prerequisite/advisory/corequisite distinctions and resolving course identifiers with explicit unresolved references. Proposed primitives: [CTDL xTRA](https://github.com/CredentialEngine/ctdl-xtra), [Lark](https://github.com/lark-parser/lark), [RDFLib](https://github.com/RDFLib/rdflib), and [pySHACL](https://github.com/RDFLib/pySHACL). A scoped grammar and typed symbol table could transfer compiler methods into catalog extraction. Merely using a parser and schema validator is insufficient differentiation.

**Buyer evidence:** [issue 208](https://github.com/CredentialEngine/ctdl-xtra/issues/208) explicitly asks for separate condition profiles and course CTID links. Its author supplies a before/after workbook and Python implementation. [Issue 259](https://github.com/CredentialEngine/ctdl-xtra/issues/259) records remaining manual corrections across multiple California institutions. These are implementation requests, not inferred buyer pain.

**Procurement status:** the [official RFP and Q&A](https://credentialengine.org/2026/07/09/credential-engine-releases-rfp-to-scale-ctdl-xtra-platform/) set an August 14 deadline and anticipated a start during the week of September 14. No award or reopening was verified. Preferred total cost is below $500,000 across three years, initially one year with extension options; this is the whole engagement, not a price for our component. Learning Tapestry remains on the implementation team. The selected partner's responsibilities must complement existing work. Pilot AI/IP-rotation costs average about $290/month before credits and exclude hosting; this does not establish large present operating-cost savings. Selected-partner benchmark access is promised, not access already obtained by us.

**Strong baseline actually inspected:** sheet 4 of the public workbook contains a pandas/regex script. It already separates prerequisite/advisory rows, tries course-code formatting variants, assigns CTIDs, and produces missing-course reports. The issue states partners confirmed the missing courses were absent from the catalog. Corequisites were absent from this example. Therefore this workbook cannot demonstrate superior corequisite handling, nor should missing references automatically count as baseline mistakes. Static inspection found no established buyer-relevant advantage for the proposed compiler mechanism. No script was executed. Spreadsheet export removes some formatting/leading characters, so the inspected text is not asserted to be an executable exact baseline.

**Input and rights:** the issue's [public workbook](https://docs.google.com/spreadsheets/d/1BiqA0tSV11HuXyOHDxdgpj1AqZhMot9-KpGHoi4uPgc/edit) was retrieved through Google's ordinary unauthenticated XLSX export: 814,548 bytes, SHA-256 `bf1feb34081ab20a147355b11b6bb1206f7b14e444e1556ee900ecb864cefd51`. It has eight sheets, including original, CTID-enriched, script, updated output, and missing-course views. No explicit workbook/embedded-script redistribution license was located. It stays outside the publication packet. Schema licensing and xTRA's Apache-2.0 license do not automatically license that workbook. Credential Engine itself distinguishes [developer and individual-use permissions](https://credentialengine.org/resources/questions-for-developers-building-a-connected-learn-and-work-ecosystem/).

**Smallest decisive next step, not yet a protocol:** at most two hours of source-only work to locate a rights-cleared, independently corrected second-campus example containing corequisites or a demonstrated failure of the buyer script. Stop if none exists. If acquired, freeze exact baseline repair rules, supported syntax, abstentions, and field-level ground truth before building a linker. Compare to the buyer script plus straightforward deterministic fixes, not raw LLM output. The desired outcome is fewer wrong/missing typed links at equal review burden; no semantic inference from course codes alone. A data permission or procurement inquiry would require separately authorized outreach. This is not an open-contract claim.

## 2. Optical-only video stabilization — HOLD

**Mechanism hypothesis:** [Gyroflow](https://github.com/gyroflow/gyroflow) + [OpenCV](https://github.com/opencv/opencv) + [GTSAM](https://github.com/borglab/gtsam), transferring robust multi-frame factor-graph estimation to separate global camera motion from local mesh residuals. A practical target would be clips whose translation/parallax makes rotation-only estimation visibly inadequate. No advantage has been measured.

[Maintainer issue 45](https://github.com/gyroflow/gyroflow/issues/45) contains a $500 bounty offer and explains that basic optical-only operation already exists; a fuller solution needs improved flow/local warping. The amount is an historical offer, not reconfirmed 2026 payment availability or repeatable economics. Current competition is material: [PR 1143](https://github.com/gyroflow/gyroflow/pull/1143) adds GMFlow through Burn/UniMatch and was updated September 5; [PR 1159](https://github.com/gyroflow/gyroflow/pull/1159) addresses optical-only render UX; [PR 1171](https://github.com/gyroflow/gyroflow/pull/1171) fixes queued optical autosync. All were open at inspection. Their reported tests are author claims, not our verification.

The strong comparison must include native optical-only mode, the current AI-flow proposal, and an established mesh-stabilization implementation, using equal crop/distortion limits. A factor graph is not useful merely because it is a different dependency. No rights-cleared real clip corpus with sufficient camera-motion truth was pinned. The project's public test-clip link does not itself establish redistribution permission. Gyroflow is GPLv3 with exceptions, OpenCV Apache-2.0; GTSAM uses a BSD license and includes separately licensed components. Exact source-license references are in `shortlist-repository-rights.json`; no binary audit was done.

**Smallest decisive next step:** source-only comparison capped at two hours to identify one unaddressed multi-frame/mesh requirement relative to PR 1143, plus lawful real clips. Kill this lead if that requirement is already covered, cannot be objectively measured, or would require a broad video pipeline just to establish basic benefit. Do not build from the age of the bounty alone.
